# SpaceX Falcon 9 First Stage Landing Prediction

## Project Overview
This project analyzes historical SpaceX Falcon 9 launch data to identify factors associated with first-stage landing success and explore whether machine learning can predict launch outcomes.

The project demonstrates the application of data science techniques, including data collection, data wrangling, exploratory data analysis, SQL, interactive visualization, and predictive modeling.

## Objectives
- Collect historical SpaceX launch data using the SpaceX API and web scraping.
- Clean and transform the collected data.
- Explore launch outcomes, payload mass, launch sites, and yearly trends.
- Perform SQL queries to analyze launch records and success rates.
- Visualize launch locations using Folium.
- Build interactive dashboards using Plotly Dash.
- Train and evaluate machine learning classification models.

## Project Workflow
1. Data Collection — retrieve launch data from the SpaceX API and relevant web sources.
2. Data Wrangling — clean missing values, standardize fields, and prepare features.
3. Exploratory Data Analysis — investigate relationships between launch outcomes, payloads, launch sites, and time.
4. SQL Analysis — query launch counts, success rates, payloads, and yearly trends.
5. Interactive Visualization — create a Folium launch-site map and Plotly Dash dashboard.
6. Predictive Analysis — train and evaluate classification models using appropriate metrics.
7. Conclusion — summarize findings, limitations, and potential applications.
